# Lab Inventory System

## Overview
This program allows the user to manage and search a database that tracks the inventory of the lab. It consists of two applications, one allowing the user to add, edit, and delete items from the database, and one that allows the user to browse and search for items.

## Instructions for launch

Open the terminal and navigate to the lab_inventory folder. You can do so using the `cd` command. For example, if the program folder is stored in "Downloads", you can enter `cd ~/Downloads` followed by `cd lab_inventory`. 

Next, you  must install the requirements. You can do so by running

`pip install -r requirements.txt`

### Windows Launch Instructions

To launch the **admin program** which allows the user to enter, edit, and delete items from the database, run

`Lab_Inventory_Admin.bat`

To launch the **viewer program** which allows the user to search and view items in the database, run

`Lab_Inventory_Viewer.bat`

The application will automatically open in your browser.

### Mac Launch Instructions

To launch the **admin program** which allows the user to enter, edit, and delete items from the database, run

`./Lab_Inventory_Admin.command`

To launch the **viewer program** which allows the user to search and view items in the database, run

`./Lab_Inventory_Viewer.command`

The application will automatically open in your browser.
